# Ovok Mobile App

Generated by [Ovok Builder](https://ovok.com/builder).

## Getting started

```bash
pnpm install
pnpm start           # Metro bundler
pnpm ios             # boot iOS simulator
pnpm android         # boot Android emulator
```

## Configuration

Copy `.env.example` to `.env.local` and fill in your Ovok tenant code
and client application ID. Both come from your project's admin panel.

## What's next

- Edit `app/index.tsx` to change the home screen.
- Add routes under `app/` — Expo Router picks them up automatically.
- `@ovok/native` (component library) and `@ovok/core` (client) are
  added in M2 of the Builder rewrite. For M1 this scaffold is a plain
  Expo Router shell that verifies as bootable.

## Stack

- Expo SDK 56
- React Native 0.85.3
- React 19.2.3
- Reanimated 4 (New Architecture required — default in SDK 56)
- Expo Router 5
- TypeScript 5.6
